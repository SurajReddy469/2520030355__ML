# RecomMind API Documentation

Base URL: `http://127.0.0.1:8000`

---

## 1. System Health & Stats

### `GET /health`
Returns the operational health and whether the trained ML model is loaded in memory.

**Response (200 OK):**
```json
{
  "status": "ok",
  "model_loaded": true
}
```

---

### `GET /stats`
Returns aggregated dataset statistics.

**Response (200 OK):**
```json
{
  "model_loaded": true,
  "total_movies": 1682,
  "total_ratings": 100000,
  "total_users": 943,
  "user_id_range": {
    "min": 1,
    "max": 943
  }
}
```

---

## 2. Recommendation Engine

### `GET /recommend/{user_id}`
Returns personalized Top-N movie recommendations generated by the hybrid model (SVD + Content-Based).

**Path Parameters:**
- `user_id` (integer, required): ID of the user (1 to 943).

**Query Parameters:**
- `n` (integer, optional, default: 10, range: 1–50): Number of recommendations to return.

**Response (200 OK):**
```json
{
  "user_id": 42,
  "count": 3,
  "recommendations": [
    {
      "item_id": 22,
      "title": "Braveheart (1995)",
      "clean_title": "Braveheart",
      "year": 1995,
      "genres": ["Action", "Drama", "War"],
      "imdb_url": "http://us.imdb.com/M/title-exact?Braveheart%20(1995)",
      "avg_rating": 4.15,
      "rating_count": 297,
      "predicted_rating": 3.814,
      "cf_score": 3.782,
      "content_score": 3.91
    }
  ]
}
```

**Errors:**
- `404 Not Found`: User ID not found in ratings dataset.
- `503 Service Unavailable`: Model not loaded.

---

### `POST /predict`
Predicts a specific user's rating for a specific movie item.

**Request Body:**
```json
{
  "user_id": 42,
  "item_id": 22
}
```

**Response (200 OK):**
```json
{
  "user_id": 42,
  "item_id": 22,
  "predicted_rating": 3.814
}
```

---

### `POST /feedback`
Accepts implicit or explicit interaction feedback events from the client.

**Request Body:**
```json
{
  "user_id": 42,
  "item_id": 22,
  "positive": true,
  "timestamp": 1776098000000
}
```

**Response (200 OK):**
```json
{
  "status": "accepted",
  "message": "Feedback received for future model updates.",
  "event": {
    "user_id": 42,
    "item_id": 22,
    "positive": true,
    "timestamp": 1776098000000
  }
}
```

## 3. Movie Discovery & Metadata

### `GET /movies`
Search, filter, and paginate through movies.

**Query Parameters:**
- `search` (string, optional): Case-insensitive title substring.
- `genre` (string, optional): Filter by genre (e.g. `Action`, `Drama`, `Sci-Fi`).
- `sort` (string, optional, default: `title`): Sort order (`title`, `year`, `rating`, `popularity`).
- `page` (integer, optional, default: 1): Page number.
- `limit` (integer, optional, default: 24, max: 100): Items per page.

**Response (200 OK):**
```json
{
  "total": 1682,
  "page": 1,
  "limit": 24,
  "total_pages": 71,
  "movies": [
    {
      "item_id": 1,
      "title": "Toy Story (1995)",
      "clean_title": "Toy Story",
      "year": 1995,
      "genres": ["Animation", "Children", "Comedy"],
      "imdb_url": "http://us.imdb.com/M/title-exact?Toy%20Story%20(1995)",
      "avg_rating": 3.88,
      "rating_count": 452
    }
  ]
}
```

---

### `GET /movies/{item_id}`
Returns details for a specific movie, including similar movies determined by genre overlap.

**Response (200 OK):**
```json
{
  "item_id": 22,
  "title": "Braveheart (1995)",
  "clean_title": "Braveheart",
  "year": 1995,
  "genres": ["Action", "Drama", "War"],
  "imdb_url": "http://us.imdb.com/M/title-exact?Braveheart%20(1995)",
  "avg_rating": 4.15,
  "rating_count": 297,
  "similar_movies": [...]
}
```

---

### `GET /genres`
Returns all available genres and movie counts.

**Response (200 OK):**
```json
{
  "genres": [
    { "name": "Drama", "count": 725 },
    { "name": "Comedy", "count": 505 },
    { "name": "Action", "count": 251 }
  ]
}
```

---

### `GET /movies/featured/popular`
Returns popular movies weighted with Bayesian average rating to favor reliable high ratings.

**Query Parameters:**
- `n` (integer, default: 12): Number of movies.

**Response (200 OK):**
```json
{
  "movies": [...]
}
```
